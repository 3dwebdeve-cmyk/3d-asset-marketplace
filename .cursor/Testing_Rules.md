# Testing Rules

Before finishing ANY task:

1. Read TESTING.md.

2. Determine every applicable test.

3. Execute every possible automated test.

4. If tests do not exist, recommend creating them.

5. Run backend tests.

6. Run frontend tests.

7. Run integration tests.

8. Run API tests.

9. Run permission tests.

10. Perform a security audit.

11. Review performance.

12. Fix every issue discovered.

13. Repeat testing until all tests pass.

14. Produce the testing report exactly as defined in TESTING.md.

Never claim tests passed unless they were actually executed.

Never fabricate test results.

Never skip testing because a task appears small.

If testing cannot be executed because tools are missing,
explicitly state:

- what could not be tested
- why
- what is required to enable testing

Never assume code is correct.
